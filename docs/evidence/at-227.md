# AT-227 — evidencia de la vertical local

## Resultado

La demo usa Google ADK 1.20.0 `InMemoryRunner` con un `BaseAgent` local sin LLM. El agente invoca `FunctionTool` para tres consultas Cypher constantes; `relate.connect(..., read_only=True)` abre el archivo en cada evaluación. No se configuró API key, modelo remoto ni servidor. El store se siembra con el dataset ficticio AT-229 y se reabre en procesos Python nuevos.

Comando de entrada desde la raíz:

```sh
uv run --frozen --extra demo python -m demo.agent.cli demo --store /tmp/estimate-at227.demo.rl
```

Salida comprobada: 60 nodos y 61 relaciones; SW-8 `INCOMPATIBLE` por ocho puertos totales frente a nueve, SW-16 `COMPATIBLE` y seleccionado con ocho PoE; al cambiar el mínimo PoE a doce, SW-16 muestra ocho medidos y deja de ser elegible; cuatro cámaras solicitadas comparten un pool de dos, mientras dos solicitadas son compatibles; UPS-1500 cumple técnicamente 1000 VA sin oferta. Cada capacidad técnica presentada conserva una ruta a una ficha ficticia.

## Gates locales

```sh
uv run --frozen --extra dev --extra demo ruff check .
uv run --frozen --extra dev --extra demo ruff format --check .
uv run --frozen --extra dev --extra demo mypy src scripts tests
uv run --frozen --extra dev --extra demo mypy demo/agent
uv run --frozen --extra dev --extra demo pytest -q
uv run --frozen --extra dev --extra demo python scripts/openapi.py --check
uv run --frozen --extra dev --extra demo python scripts/check_secrets.py
```

Resultado en la base inicial `c130fda`: Ruff y ambos mypy sin errores; 68 tests pasaron con una advertencia deprecada de Starlette/AnyIO; OpenAPI coincide y no se detectaron secretos. `develop` avanzó durante la preparación. En un clon público nuevo de la base `c503575e152430908da3f0bb56317867e77d26c9` con el parche preparado, el comando único produjo las cinco evaluaciones y la suite completa terminó **69 passed, 1 warning**. En la rama final sobre esa base: Ruff, ambos mypy, OpenAPI, escaneo de secretos y lockfile pasaron; 69 tests con extra `demo`, y 61 tests con extra `dev` más un módulo de demo omitido por faltar la dependencia opcional. La validación OpenSpec estricta pasó después de archivar. El workflow dedicado repite el test de CLI en CI con dependencias fijadas por `uv.lock`.

## Límites

La demo no prueba proveedor LLM, endpoint de FastAPI, UI, disponibilidad real, proveedores, SQL, despliegue ni Devpost. `selectedProductId: null` impide presentar como compra un producto técnicamente válido sin oferta. El archivo Relate local sólo debe usarse con la fixture ficticia; la protección contra dos escritores y restauración se evaluó en AT-215, no aquí.
