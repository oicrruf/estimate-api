# Propuesta: extracción privada OpenAI sobre el fixture guiado

Añadir CLI locales y aisladas que extraen alcance preliminar de texto
sintético en español mediante una sola petición OpenAI. El modelo
predeterminado es `gpt-6-luna`, decidido por el propietario. ADK invoca
después la herramienta fija Relate del fixture cuando la cantidad está
definida; sólo el cálculo determinista decide elegibilidad y stock. No se
modifica el GET determinista ni el despliegue.

Este cambio es **activo**: esta rama aún no ejecutó una comprobación privada
real con OpenAI. La prueba real de Luna que informó otra tarea es independiente
y no se atribuye a este corte. Ningún endpoint pago,
alojamiento, cliente real, precio, aprobación de compra o credencial en repo.
