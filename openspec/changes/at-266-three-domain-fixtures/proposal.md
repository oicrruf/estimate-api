# Proposal

## Context

AT-264 aporta el documento universal y AT-265 el registro de cobertura. AT-240 sigue en curso; esta propuesta prepara casos reproducibles para su posterior integración sin atribuir al registro capacidad de descubrimiento.

## Change

Añadir tres casos ficticios de cámaras, pintura y evento audiovisual con cantidades declaradas, referencias exactas a paquetes versionados y un contrato tipado de entrada para pruebas. Un recorrido genérico de dependencias en el arnés de tests demuestra partidas omitidas y cambios de cantidad; no forma parte del pipeline de producción.

## Scope

Incluye fixtures, pruebas de aislamiento y evidencia local. Excluye reglas profesionales, normas, precios, aprobación técnica, conexión a AT-240, API o persistencia.
